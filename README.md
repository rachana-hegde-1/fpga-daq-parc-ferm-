# FPGA DAQ — PARC FERM

Simulation-first FPGA-based data acquisition system for vehicle measurements.

## Objectives
- Develop synthesizable RTL measurement modules.
- Verify behaviour using testbenches and waveform analysis.
- Evaluate synthesis results and resource utilization.
- Document requirements, architecture, assumptions, and component choices.

## Initial milestone
RPM pulse-period measurement with reset and missing-pulse timeout handling.

## Scope limitations
This project initially targets RTL simulation and synthesis. Physical hardware
integration and compatibility with actual vehicle sensors are not yet verified.

## Tools
- Verilog/SystemVerilog
- Icarus Verilog
- GTKWave
- FPGA synthesis tool (target TBD)
